See who's in the room. Without a camera.

// what

What it is

Every Wi-Fi packet carries a channel state information vector — a fingerprint of the multipath between two radios. Move a body through the room and that fingerprint deforms in predictable ways.

MantisSec is the whole stack for building a room-scale presence sensor out of that signal. Three ESP32-C3 beacons transmit at a known cadence. Two ESP32-S3 receivers catch the beacons, extract CSI, run an inverse sensor model, and paint a live top-down map on a little screen.

All firmware is open source. All hardware is off-the-shelf. Nothing calls home. Nothing sees inside your walls. It's just wi-fi doing what wi-fi does — with math on top.

// how

How you set it up

  1. Flash the firmware. Plug each board into any computer with Chrome or Edge, click one button per board. → go to the web flasher
  2. Place the hardware. Put the three beacons around the room in a rough triangle. Put the receiver bar in the middle. No wiring, no room modelling.
  3. Walk the calibration. The device walks you through a one-time cal walk to each beacon and back. Takes about 90 seconds.
  4. Observe. Live top-down map on the receiver screen — see who moves through the room in real time.
